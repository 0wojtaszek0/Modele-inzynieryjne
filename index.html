Technical Model

Quarter-Car System Equations

The 2-DOF model consists of two masses — sprung (vehicle body) and unsprung (wheel assembly) — connected by springs and dampers.

Unsprung mass equation
m·ẍm = −(kM+km)xm + kMxM −(cM+cm)ẋm + cMẋM + kmz(t) + cmż(t)
Sprung mass equation
M·ẍM = kMxm − kMxM + cMẋm − cMẋM
Platform excitation
z(t) = −d · cos(θ(t))    d = 3 mm amplitude (6 mm peak-to-peak)

Performance Metrics

Key Performance Indicators

φ

Minimum Phase Shift

Primary indicator of damper performance, measured during 18→6 Hz sweep.

φmin = arccos( (Fmin − F̄) / (ΔF/2) )
< 30° Too stiff or worn
30°–60° Good performance
> 60° Too soft or over-extended
%

EUSAMA Index

Wheel load retention at resonance relative to static load.

EUSAMA = (Fmin / Fst) × 100%
≥ 50% Functional damper
< 50% Possibly defective
RFA

Relative Force Amplitude

Maximum force oscillation relative to static wheel load.

RFAmax = max(ΔF) / Fst × 100%
Higher RFA indicates more dynamic force variation.

Compliance

EGEA Standard Parameters

All measurements and calculations conform to the EGEA (European Gauge of Automotive) specification.

Standard Parameter Value / Range Tolerance
Minimum Phase Shift (φmin) 0–180° ±3° (for values >30°)
Static Force (Fst) 100–1100 daN ±2%
RFAmax 0–100% ±5%
Excitation Frequency Range 25–5 Hz ±1 Hz
Platform Stroke (peak-to-peak) 6 mm ±0.3 mm
Measurement Phase Duration 7.5 s (18→6 Hz) ±2 Hz
Stabilisation Time at 25 Hz Fst × 0.16 + 1200 ms —
